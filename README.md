# Predict Healthcare Costs with Regression 

## About the Project
A machine learning regression model built using TensorFlow and Keras to predict individual healthcare costs based on features such as age, sex, BMI, number of children, smoking status, and region. The model achieves a Mean Absolute Error (MAE) of under $3,500 on unseen test data.

## Technologies Used
- Python
- Pandas / NumPy
- TensorFlow / Keras (Sequential API, Dense layers)
- Matplotlib / Google Colab
